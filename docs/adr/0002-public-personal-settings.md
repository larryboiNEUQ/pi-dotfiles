# 公开个人参数，排除密钥

接受问卷 A1、A2、A3 和 S3 的决定。仓库保持公开，默认入口恢复所有纳管配置，`--public` 只恢复公共配置。公开个人模型和权限参数减少多台机器的配置差异，代价是这些偏好对访客可见。

配置按字段白名单导出。凭证、设备标识、信任记录、会话、缓存、日志、备份和安装状态不入库。未知字段只报告名称，不输出值。LangSmith 只纳管 `enabled`、`api_url` 和 `project`，应用保留本机 `api_key`。

pi-pstack 的三个 agent 定义和两个配置模板登记为外部拥有项。skills 和 Herdr 集成不纳管。B4 的备注覆盖“不确定”状态，仓库停止安装 MCP adapter，也不写入关闭内置 MCP 的设置。本次不迁移真实本机 MCP。
