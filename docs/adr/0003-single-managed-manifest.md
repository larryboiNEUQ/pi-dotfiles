# 用一份纳管清单驱动全部同步操作

接受问卷 C1–C7、S5–S7 的决定。审计、导出和应用共用一份纳管清单，本机保存不含凭证的同步基线。JSON 参数按字段比较，数组、agent Markdown 和扩展代码按整体比较，避免安装范围和导出范围分别维护后产生差异。

任何冲突或必要确认在写入和升级前阻止整批操作。无交互时停止并返回非零状态。配置写入前备份，执行失败时恢复本批配置，插件已完成的升级不回滚。

缺失不代表删除。恢复默认、删除纳管文件和卸载纳管插件使用显式删除记录，记录保留到所有者清理。待分类项不阻止已纳管内容同步，但审计报告覆盖不完整。接受本机基线和持久删除记录的维护成本，换取单侧修改识别与可解释的删除行为。
