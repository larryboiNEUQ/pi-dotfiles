# Domain docs

本仓库采用单上下文布局。根目录 `CONTEXT.md` 是领域术语表，`docs/adr/` 保存架构决定。

## 探索前读取

1. 读取根目录 `CONTEXT.md`。
2. 读取与当前工作有关的 `docs/adr/` 文档。
3. 如果以后出现 `CONTEXT-MAP.md`，先读取该地图，再读取相关上下文的术语表与 ADR。

文档缺失时继续工作，不为了补齐模板主动创建文件。领域概念明确后，由 domain-modeling 流程记录。

## 使用术语

票、规格、测试和设计使用 `CONTEXT.md` 定义的术语。不要使用术语表明确排除的近义词。尚未定义的实际领域概念需要记录为术语缺口。

## ADR 冲突

新建议与已有 ADR 冲突时，明确指出 ADR 编号和重新讨论的原因。不静默覆盖决定。`CONTEXT.md` 只写术语定义，不放实现计划或脚本细节。
